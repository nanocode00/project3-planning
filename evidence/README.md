# 증거 기록 양식

아직 프로젝트 구현·측정·제출 증거는 없습니다. 원문 수집 증거는 `sources/`에 있습니다. 아래 표를 복사해 완료 항목마다 채웁니다. 링크가 비공개면 누가 어떻게 볼 수 있는지도 기록하되 비밀번호·API 키는 저장하지 않습니다.

| 기준 ID | 담당/검토자 | 확인일(KST) | 코드 SHA | 데이터/평가셋 해시 | 명령·환경 | 실제 결과(건수/분모·시간·비용) | 증거 경로/URL | 한계/다음 일 |
|---|---|---|---|---|---|---|---|---|
| 미기록 | 미정 | 미기록 | 미기록 | 미기록 | 미기록 | 미측정 | 미기록 | 미기록 |

동일 증거가 여러 기준을 충족하면 기준 ID를 함께 적습니다. 같은 체크를 문서 수만큼 중복 집계하지 않습니다. 정적 확인·기록 응답 재생·새 환경 실행·라이브 API·배포 실행은 확인 종류를 나눠 적습니다.

|---|---|---|---|---|---|
| 미정 | 미정 | 미정 | 미정 | 미측정 | 미기록 |

결과를 본 뒤 기대 칸을 고치지 않습니다. 원시 결과·제외 문항·코드 SHA·모델·캐시 여부를 연결합니다. 재생은 실제 API 비용·지연 측정을 대신하지 않습니다.
