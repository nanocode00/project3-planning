# 3차 프로젝트 준비 체크리스트

3인 팀의 프로젝트 준비 자료를 공유하는 저장소입니다. 공식 안내의 2026-10-26 스냅샷과 10/28까지 정리한 수업 대응·팀 정책을 포함합니다. 공식 조 저장소를 대체하지 않습니다.

아이디어·개별 주제 기획안은 공유 대상에서 제외했습니다. 주제서 빈 양식은 유지합니다.

## 어디부터 볼까

[필수 게이트](docs/GATES.md)와 [평가 기준](docs/EVALUATION.md)에서 요구조건을 확인하고, [날짜별 일정](docs/SCHEDULE.md)과 [팀 운영 정책](docs/TEAM_POLICY.md)으로 작업을 준비합니다.

수업 원본의 로컬 절대 경로 링크는 자료를 정리한 컴퓨터 기준입니다. 이 저장소에는 강의 원본을 복제하지 않았으므로 다른 환경에서는 원본 자료 경로를 맞춰야 합니다.

## 사용 규칙

- `[ ]`는 미확인입니다. **증거와 확인일을 기록한 뒤** `[x]`로 바꿉니다. 문서를 만들었다는 이유로 구현 완료를 체크하지 않습니다.
- G1~G7의 완료 상태는 `docs/GATES.md`에서 관리합니다. 출처별 문서는 원문 누락 확인용이며 실제 진척의 중복 집계에 쓰지 않습니다.
- 공식 숫자는 `공식`, 날짜별 실행 순서·분담 제안은 `팀 제안`, 해석이 필요한 것은 `확인 필요`로 표시했습니다.
- 별도 점수가 공개되지 않은 세부 항목에는 배점을 만들지 않았습니다. 정확도·Recall·응답 시간의 공식 합격 수치는 공개되지 않았습니다.
- 담당 A/B/C는 자리표시자입니다. 모든 실제 결과는 미측정이며 점수도 미채점입니다.
- 수업 적용 가이드는 2026-10-28 추가된 `3. 멀티에이전트 오케스트레이션` 01~19강까지 정적으로 확인했습니다. 강의 재실행·API/DB/학습/배포 검증은 하지 않았습니다. 메모리 예제·LIGHT 재생·학습 dry-run의 한계와 프로젝트 추가 구현을 구분했습니다.

## 핵심 숫자

| 항목 | 공식 기준 |
|---|---|
| 기본 배점 | 15 + 25 + 25 + 20 + 15 = 100점 |
| 게이트 감점 | G1~G7 합계 최대 −50점 |
| 가산점 | 4종 합계 16점, 적용 상한 +10점; 게이트 전부 충족 시만 |
| 코퍼스 | 서로 다른 문서 ≥50건, 본문 SHA-256이 다른 청크 ≥10,000개; 20,000개는 권장 |
| 에이전트 | Supervisor 1개 + 서브에이전트 ≥2개, 사람 승인 ≥1곳 |
| 평가셋 | v1 30건(15+15), v2 ≥50건(관련·비관련 1:1), 해시 동결 |
| 평가 | 개선 전후 두 번 이상 재측정, 단일·멀티를 같은 v2로 비교 |
| 실행 | 키 없는 데모 포함 `docker compose up`, ≤10분 |
| 기타 증거 | 파싱 원문 대조 ≥3건, 변이 검증 ≥3건, 인젝션·출처 유출 시험 ≥3건 |
| 제출 | 테스트 계정 2개, Langfuse 스크린샷 ≥3장(상세 ≥1장), 영상 ≤180초 |
| 예산·시간 | 조당 OpenRouter $30, 프로젝트 100시간(교육 일정 기준) |
